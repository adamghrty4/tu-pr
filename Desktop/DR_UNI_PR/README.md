# Student Scores Analysis Project

This project focuses on cleaning and analyzing student test scores to understand the impact of various factors, such as parental education, on performance.

## Project Structure

The project follows a two-step workflow:

1.  **Data Cleaning**: [src/cleaning.ipynb](src/cleaning.ipynb)
    - Initial data exploration and preprocessing.
    - Handling missing values and data type conversions.
    - Exporting `cleaned_Scores.csv`.

2.  **Data Analysis**: [src/question2.ipynb](src/question2.ipynb)
    - Statistical analysis of scores based on parental education levels.
    - Visualizing distributions and mean scores.
    - Hypothesis testing (ANOVA/Kruskal-Wallis).
